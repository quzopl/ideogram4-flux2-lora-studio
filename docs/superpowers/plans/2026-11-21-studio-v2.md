# Studio v2.0 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Studio v2.0 to nowe, animowane UI (React) oraz kilka nowych funkcji:
wybór katalogu modeli (dla pobierania i dla modeli już istniejących),
pobieranie z wyborem katalogu i postępem, zapis ustawień i presetów, upscale
x2/x3/x4 z wyborem GPU i modelu, a także GPU przypisywane per rola.

**Architecture:** Backend FastAPI zostaje i dostaje trzy nowe moduły:
`settings.py` (jeden magazyn ustawień), `model_store.py` (rejestr modeli,
lokalizacje, pobieranie) oraz rozszerzenie `gpu.py` o role. Nowy frontend
powstaje obok w `web/` (React + Vite) i jest serwowany pod `/`. Stary
`frontend/` działa pod `/legacy/` do czasu parytetu, potem jest usuwany.

**Tech Stack:** Python 3.12, FastAPI 0.136, transformers 5.9,
huggingface_hub 1.17, torch 2.12+cu130, spandrel, pytest. W `web/`: React 19,
TypeScript, Vite, Tailwind CSS v4, shadcn/ui, Motion, TanStack Query,
react-router 7, sonner, lucide-react, Playwright. Menedżer pakietów: pnpm.

**Spec:** `docs/superpowers/specs/2026-11-21-studio-v2-design.md`

### Task 2b: Strażnik pochodzenia żądań (CSRF i DNS rebinding)

Zadanie dodane po automatycznym przeglądzie bezpieczeństwa Task 2. Problem
dotyczy całego API: dowolna strona otwarta w przeglądarce może wysłać `POST`
na `http://127.0.0.1:8123/api/...`. Przy `fetch` z `mode: "no-cors"` i
`Blob` bez typu FastAPI parsuje body jako JSON. Nowe endpointy (import
ustawień, `models_dir`, pobieranie do folderu, mkdir) zwiększają skutki
takiego ataku.

**Files:**
- Create: `backend/origin_guard.py`
- Modify: `backend/server.py` (`app.add_middleware(...)` zaraz po utworzeniu
  `app`)
- Test: `tests/test_origin_guard.py`

**Interfaces:**
- Produces:
  - `is_loopback_host(host: str) -> bool`. Wejściem jest nagłówek `Host` albo
    host z `Origin`, z portem lub bez. Wynik jest True dla `127.0.0.1`,
    `localhost`, `::1` i `[::1]`, a False dla wszystkiego innego, także dla
    pustego stringa.
  - `class OriginGuard` (czysty ASGI middleware albo `BaseHTTPMiddleware`)
    obejmuje tylko ścieżki zaczynające się od `/api/` i stosuje trzy reguły:
    1. Gdy nagłówek `Host` nie jest loopbackiem, odpowiedź to 403
       `{"detail": "Forbidden host."}`. Ta reguła blokuje DNS rebinding.
    2. Dla metod innych niż GET, HEAD i OPTIONS: gdy jest nagłówek `Origin`, a
       jego host nie jest loopbackiem (albo `Origin` ma wartość `null`),
       odpowiedź to 403 `{"detail": "Cross-origin request blocked."}`. Port
       nie jest porównywany, dzięki czemu dev serwer Vite na innym porcie
       localhost działa.
    3. Dla metod innych niż GET, HEAD i OPTIONS: `Sec-Fetch-Site: cross-site`
       daje 403 z tym samym komunikatem.
  - Żądania bez `Origin` (curl, testy, skrypty) przechodzą, o ile `Host` jest
    loopbackiem.
